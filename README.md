# Paradise Nursery

A modern houseplant shopping application built with React, Redux Toolkit, React Router, and Vite.

## Project Description

Paradise Nursery is a frontend e-commerce application that allows users to browse houseplants, add products to a shopping cart, adjust quantities, remove products, and view their total order cost.

## Features
- Responsive landing page
- Company information section
- Houseplant product listing
- Product categorization
- Add to cart functionality
- Disabled add button after selection
- Dynamic shopping cart count
- Redux Toolkit state management
- Increase/decrease quantity
- Delete cart items
- Order summary
- Continue shopping
- Checkout "Coming Soon" functionality

## Technologies
- React
- Redux Toolkit
- React Redux
- React Router
- JavaScript
- CSS3
- Vite

## Run Locally

```bash
npm install
npm run dev
```
